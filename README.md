# COMPASS Project Page

This repository hosts the project website for:

**COMPASS: Confined-space Manipulation Planning with Active Sensing Strategy**

Accepted by **IEEE International Conference on Robotics and Automation (ICRA) 2026**.

## Contents

- `index.html`: main project page
- `static/css/index.css`: page styling
- `static/js/index.js`: scroll interaction
- `static/pdfs/COMPASS_ICRA_Final.pdf`: paper PDF
- `static/images/compass/`: paper figures and rendered preview assets

## Local Preview

Open `index.html` directly in a browser, or serve the directory with any static server.
